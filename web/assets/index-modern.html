    Politique de Confidentialité

    Ce service de test de vitesse Yele est configuré avec la télémétrie activée.

    Quelles données nous collectons

    À la fin du test, les données suivantes sont collectées et stockées:

    • ID du test
    • Date et heure du test
    • Résultats du test (vitesse de téléchargement et d'upload, ping et jitter)
    • Adresse IP
    • Informations du fournisseur d'accès (FAI)
    • Localisation approximative (déterminée par l'adresse IP, pas GPS)
    • User agent et langue du navigateur
    • Journal du test (ne contient pas d'informations personnelles)

    Comment nous utilisons les données

    Les données collectées via ce service sont utilisées pour:

    • Permettre le partage des résultats du test (image partageable, etc.)
    • Améliorer le service offert (par exemple, détecter les problèmes)

    Aucune information personnelle n'est divulguée à des tiers.

    Votre consentement

    En démarrant le test, vous consentez aux termes de cette politique de confidentialité.

    Suppression des données

    Si vous souhaitez faire supprimer vos informations, vous devez fournir soit l'ID du test, soit votre adresse IP. C'est la seule façon d'identifier vos données.

    Contactez l'adresse email suivante pour toute demande de suppression: À REMPLIR PAR LE DÉVELOPPEUR.
